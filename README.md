Personal portfolio site, served with GitHub Pages at <https://maitykunal2004.github.io>.

Single static page, no build step, no dependencies. Open `index.html` in a browser to view it locally.

- [Automated Financial Invoice Extractor](https://github.com/maitykunal2004/automated-financial-invoice-extractor) - Gemini 2.5 Flash vision extraction with Pydantic schema validation and arithmetic reconciliation.

All project data is synthetic. No employer or client data appears here.
